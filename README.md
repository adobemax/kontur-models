# Пакеты моделей «Ширмы»

Отдельное хранилище моделей для [приложения «Ширма»](https://github.com/adobemax/shirma) —
локального обезличивания документов. Раньше приложение называлось «Контур», а хранилище —
kontur-models; старые адреса GitHub перенаправляет сюда.

Модель лежит здесь, а не в установщике, намеренно: она весит больше ста мегабайт и обновляется
отдельно от приложения. Установщик от этого не растёт, а пользователь ставит модель один раз и
только если она ему нужна.

## Что внутри

| Пакет | Задача | Сущности | Размер | Лицензия |
| --- | --- | --- | ---: | --- |
| `ru-ner-collection3` | поиск сущностей в русском тексте | ФИО, организации, места | 116 МБ | Apache 2.0 |

Пакет — это ZIP с моделью в формате ONNX, словарём токенизатора и манифестом. Приложение
исполняет его через `onnxruntime` прямо в главном процессе: Python не нужен.

## Как приложение его получает

1. Читает `manifest.json` этого репозитория — там версия, размер и контрольная сумма архива.
2. Скачивает архив из раздела релизов.
3. Проверяет sha256 архива, затем sha256 каждого файла внутри.
4. Распаковывает в служебный каталог пользователя.

Скачивание происходит **только по явному действию пользователя** и только на экране установки.
Во время обработки документов приложение в сеть не выходит: это его главное свойство, и загрузка
модели вынесена за пределы этого пути намеренно.

Контрольная сумма проверяется до распаковки. Всё, что пришло по сети, доверия не заслуживает —
даже из собственного репозитория.

## Почему именно эта модель

Выбрана по замеру на размеченном корпусе из 150 документов договорного вида. Полное покрытие
упоминаний ФИО: правила приложения — 79%, модель — 93%, вместе — 99%. По организациям правила
дают 47%, модель — 68%.

Квантование в int8 уменьшило файл с 711 до 178 МБ и не ухудшило качество: покрытие совпало до
упоминания, а скорость выросла.

## Как собрать пакет заново

```bash
python -m venv venv && ./venv/bin/pip install "optimum[onnxruntime]" transformers torch
./venv/bin/python tools/export.py build
./venv/bin/python tools/package.py build dist LICENSE 1.0.0
```

Сборка воспроизводима: `tools/export.py` берёт модель по имени с Hugging Face и выполняет только
экспорт и квантование. Ни архитектура, ни веса иначе не меняются — см. `NOTICE`.

## Лицензии

Модель и производные от неё файлы распространяются под Apache License 2.0 — текст в `LICENSE`,
перечень изменений в `NOTICE`. Под той же лицензией распространяются скрипты сборки.
